Leonida Trophy Guide — an offline tracker and guide for all 55 Grand Theft Auto VI trophies on PlayStation 5 (1 platinum, 2 gold, 6 silver, 46 bronze). A checklist saved in the browser with export and import, filters by grade and kind (story, missable, collectibles, activities — this list has no online trophies), a spoiler-safe mode that hides un-earned story trophies, a six-stage roadmap to the platinum, and a missables page flagging the 17 story-gated trophies. Every trophy's guide is written in our own words from the official trophy description and cites its sources (Exophase and PSNProfiles); anything beyond the description is labelled as our own advice, not yet checked in the game. No Rockstar logo or artwork, no network needed.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — the guide runs entirely from its own files, offline.

To build the submission output instead:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
